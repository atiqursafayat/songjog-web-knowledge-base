# Songjog Mintlify Knowledge Base

## Deploy
1. Create a private GitHub repository and upload all files from this folder.
2. In Mintlify, create a new documentation project from that repository.
3. Deploy and choose a short public URL, for example `https://songjog-web.mintlify.app`.
4. Review all Draft records and replace placeholders with approved organization facts.
5. If the site must be used by Microsoft 365 Copilot Agent Builder as a public website source, keep the content non-sensitive and publicly accessible.
6. Add the root Mintlify URL to Agent Builder. Do not add deep page URLs or query parameters.

## Local preview
Install the Mintlify CLI according to the current Mintlify documentation, then run the development command from this directory.

## Security
This repository sets `robots` to `noindex, nofollow`, but that does not make a public deployment private. Never publish personal data, confidential reports, consent records, API secrets, MCP credentials, or unpublished legal and financial information.
