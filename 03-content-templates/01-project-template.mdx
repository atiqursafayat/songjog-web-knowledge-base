## Purpose

Define a structured initiative with its own goals, activities, and expected results.

## Required inputs

Project name; responsible entity; purpose; location; period; target participants; verified activities; evidence; status; Focus Area; approved media.

## Recommended structure

H1 project name; summary; context; project approach; activities; participation; verified results; next steps; related focus area; CTA.

## Required handoff

Excerpt; slug; status; taxonomies; SEO; featured image; alt text; internal links; evidence ledger.

## Agent checklist

- Use supported facts only.

- Ask blocking questions before finalizing.

- Provide human-readable draft and structured JSON.

- Default to Draft status.
