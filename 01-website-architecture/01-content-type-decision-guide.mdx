## Decision table

| Material describes | Create | Classification |
| --- | --- | --- |
| A structured initiative Songjog operates | Project | Focus Area + Project Status |
| Progress within an existing project | Post | Project Updates |
| A completed field activity | Post | Field Stories or Updates |
| A scheduled or completed public event | Post | Events |
| Research, analysis, or lessons | Post | Insights |
| A first-person human experience | Post | Stories |
| Vacancy, tender, AGM, deadline, urgent alert | Notice | Notice Category + Status |
| External media coverage | Press | Press Category + Focus Area |
| Annual, audit, or formal publication | Report | Report Category |
| Approved short testimony | Quote | Quote Status |
| One-off institutional information | Page | No standard taxonomy |

## Classification questions

- Is this a repeatable content object or a one-off page?

- Is Songjog the publisher or is it external media coverage?

- Does it describe a project itself or an update inside a project?

- Is the information time-sensitive and official?

- Does a direct, consented quotation merit a related Quote object?

| RULE: Blog is the overall section. Individual Posts use controlled categories: Updates, Events, Field Stories, Insights, Project Updates, or Stories. |
