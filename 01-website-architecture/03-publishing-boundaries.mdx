> Draft-first governance and restricted actions

<Note>
**Document control**

- **Knowledge use:** AUTHORITATIVE AFTER APPROVAL
- **Responsible entity:** Songjog Foundation USA website

## Routine draft actions

- Read content types and taxonomies.

- Search existing projects and related posts.

- Check slug availability.

- Create draft content items.

- Set approved taxonomies and SEO metadata.

- Attach approved existing media.

- Create preview links.

## Approval-required actions

- Publish or update published content.

- Delete content.

- Change navigation or template display conditions.

- Change global styles, plugins, users, or custom code.

- Modify donation products, payments, forms, or routing.

- Change homepage feature assignments.

- Push staging to production.

## Environment rules

- Work on staging first.

- Purge LiteSpeed page and object caches after edits.

- Do not leave Elementor open when another editor is working.

- Require backup and rollback before production deployment.
