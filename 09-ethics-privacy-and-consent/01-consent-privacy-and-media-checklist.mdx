## Blocking checks

| Check | Pass condition |
| --- | --- |
| Direct quotation | Exact words and approved attribution are available |
| Consent | Public website use is confirmed |
| Identification | Naming or showing the individual is safe |
| Children | Applicable safeguarding approval is documented |
| Sensitive data | Unnecessary medical, financial, legal, and protection details are removed |
| Photography | Image is real, authorized Songjog media |
| Alt text | Describes meaningful visible content without inventing identity |

## If a check fails

- Block the related Quote or personal story.

- Offer a non-identifying activity summary.

- Request consent or authorization.

- Do not infer missing information from images.
