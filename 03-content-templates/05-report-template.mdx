## Purpose

Publish an annual, audit, financial, or formal downloadable publication.

## Required inputs

Official title; reporting period; category; approved file; cover; publication date; responsible entity.

## Recommended structure

H1 report title; short description; reporting period; key contents; file download; related organizational links.

## Required handoff

Report Category; file URL or ID; cover media; SEO; entity verification.

## Agent checklist

- Use supported facts only.

- Ask blocking questions before finalizing.

- Provide human-readable draft and structured JSON.

- Default to Draft status.
